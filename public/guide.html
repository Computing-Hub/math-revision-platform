How to play

1. Answer a question

  1. Click the white answer box under the question.
  2. Type your answer (see below for fractions and powers).
  3. Press Enter or the Check button.

You can use the Show my working box for rough work. Only the answer box is marked.

On a tablet or phone? Press ⌨️ Maths keyboard next to the answer box. It has buttons for fractions (□/□), powers (□²), the letters in the question, and numbers.

3. Solving equations with two answers

Quadratic equations usually have two solutions. Type one in the x₁ = box and the other in the x₂ = box, in any order. If both solutions are the same number, you only need to type it once.

If an equation has no real solutions, tick the box that says so.

The Maths keyboard has the quadratic formula on one button, to help with your working.

4. How answers are checked

  • Answers are checked by their value: 3/4 and 0.75 both count, and so does writing terms in a different order.
  • Answers with letters are checked by trying numbers for the letters. So 7x/10 is right, but 7/10 or 7y/10 are not.
  • If a question says simplify fully or as a single fraction, a right value in the wrong form is marked 🟡 Nearly. That doesn't use up a try: fix it and check again.

5. Stars

  • You get 3 tries for each question.
  • Right first time: ⭐⭐⭐. Second try: ⭐⭐. Third try: ⭐.
  • After 3 wrong tries, the answer is shown so you can see how it should look.
  • Your best score for each worksheet is shown on the home page (on this device).
